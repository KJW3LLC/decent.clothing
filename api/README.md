# decent.clothing API

decent.clothing exposes static JSON endpoints generated by Jekyll.

## Endpoints

- `/api/guides.json`: all articles with metadata
- `/api/topics.json`: topic tags and related articles
- `/api/series.json`: article series metadata
- `/index.json`: site index, navigation, and article-type counts

## Article Object

```json
{
  "id": "the-denim-fit-guide-straight-relaxed-loose-and-what-actually-changes",
  "title": "The Denim Fit Guide: Straight, Relaxed, Loose, and What Actually Changes",
  "slug": "the-denim-fit-guide-straight-relaxed-loose-and-what-actually-changes",
  "url": "https://decent.clothing/guides/the-denim-fit-guide-straight-relaxed-loose-and-what-actually-changes/",
  "description": "A Style Guides article on denim fits and how their silhouettes differ",
  "article_type": "style-guides",
  "tags": ["style-guides", "denim", "fit"],
  "estimated_time": "5 min read",
  "date_published": "2026-07-10T00:00:00+00:00"
}
```

## Article Types

- `style-guides`
- `designer-spotlight`
- `shop-spotlight`

## Example

```js
fetch('/api/guides.json')
  .then(response => response.json())
  .then(data => {
    const styleGuides = data.articles.filter(article => article.article_type === 'style-guides');
    console.log(styleGuides);
  });
```
