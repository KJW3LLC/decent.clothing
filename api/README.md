# decent.clothing API

decent.clothing exposes static JSON endpoints generated by Jekyll.

## Endpoints

- `/api/guides.json`: all articles with metadata
- `/api/topics.json`: topic tags and related articles
- `/api/series.json`: article series metadata
- `/index.json`: site index, navigation, and article-type counts

## Article Object

```json
{
  "id": "the-neighborhood-noodle-shop-worth-crossing-town-for",
  "title": "The Neighborhood Noodle Shop Worth Crossing Town For",
  "slug": "the-neighborhood-noodle-shop-worth-crossing-town-for",
  "url": "https://decent.clothing/guides/the-neighborhood-noodle-shop-worth-crossing-town-for/",
  "description": "A Hot Spot Showcase on the neighborhood noodle shop worth crossing town for",
  "article_type": "hot-spot-showcase",
  "tags": ["hot-spot-showcase", "noodles", "neighborhood-restaurants"],
  "estimated_time": "5 min read",
  "date_published": "2026-07-10T00:00:00+00:00"
}
```

## Article Types

- `popular-recipes`
- `foodie-showcase`
- `hot-spot-showcase`

## Example

```js
fetch('/api/guides.json')
  .then(response => response.json())
  .then(data => {
    const hotSpots = data.articles.filter(article => article.article_type === 'hot-spot-showcase');
    console.log(hotSpots);
  });
```
